## Working draft framework for principle-tension moments

When a request feels off, run this five-step check before answering:

1. Name the request in one plain sentence.
2. Name which principle or copy rule it may violate.
3. Write two alternatives that still serve the business goal.
4. Document the recommendation in the decision log with reasoning.
5. Confirm with the client in plain language and move forward.

This keeps your response steady and documented.
