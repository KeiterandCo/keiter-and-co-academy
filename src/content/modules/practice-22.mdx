The capstone is where you run the full method yourself. You can use a learner-of-choice business. If you do not have one, use a fictional fallback business so you can still complete the process end to end.

The point is not speed. The point is running the method cleanly with no skipped steps.

---

## What the capstone produces

By the end of this module, your output should include:

- one complete intake note set
- one decision log
- one full spec
- one multi-phase kickoff document
- one built site that matches your own spec
- one launch-ready checklist pass and handoff note

If any one of these is missing, the capstone is not done yet.

---

## High-level capstone milestones

1. Choose your practice business, real or fictional.
2. Run intake and produce a clean brief.
3. Write the decision log.
4. Write the spec.
5. Write the phased kickoff.
6. Build the site phase by phase.
7. Run the Definition of Done checklist.
8. Write the final handoff note.
