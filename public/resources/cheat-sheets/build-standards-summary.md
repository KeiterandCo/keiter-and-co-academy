# Build Standards Summary

## Accessibility

- WCAG 2.2 AA
- Semantic HTML first
- Keyboard access for every interactive element
- Visible focus states
- Labeled form fields
- Contrast checked on every text and background pair

## Mobile

- Check 375px, 768px, 1280px
- Touch targets large enough to use comfortably
- Navigation works on a phone before launch

## Content and search

- Meta titles and descriptions are written as answers
- Schema where it helps
- Plain-language page structure
- Search indexing works on the built site

## Personality and polish

- Motion is present and restrained
- Hover states exist on interactive elements
- At least one SVG personality moment where it belongs
- Images have real descriptions and planned aspect ratios
- Print stylesheet is clean
- 404 page is branded

## Launch checks

- Analytics only if configured correctly
- OG image and favicon in place
- Footer and CTA paths reviewed
- BUILDNOTES reflects anything still open
