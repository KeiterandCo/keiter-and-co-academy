# Definition Of Done Checklist

Run this before you call any build complete.

## Copy and voice

- Voice matches the business.
- No banned phrases or formatting drift.
- Plain language where technical ideas appear.

## Accessibility

- Keyboard path works.
- Focus styles are visible.
- Contrast is checked.
- Semantic HTML is in place.

## Mobile

- Layout holds at phone, tablet, desktop.
- Mobile nav works.
- Touch targets are usable.

## Search and metadata

- Meta title and description written.
- OpenGraph present.
- Search indexing works.
- Schema added where appropriate.

## Media and polish

- Image slots have descriptions.
- Fonts load cleanly.
- 404 page is branded.
- Print view is readable.

## Final build discipline

- Local build passes.
- Deferred items are in BUILDNOTES.
- Phase handoff note is written.
- Human review happened before anything goes out.
